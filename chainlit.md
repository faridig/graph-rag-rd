# Base de connaissances R&D — ACCRO

Système de questions-réponses sur les expériences d'extrusion et d'application ACCRO.

## Corpus

- **170 expériences** · 2 371 runs · 3 072 blocs de données
- Données issues de SharePoint : fiches d'essais, résultats analytiques, synthèses

## Types de questions supportées

| Type | Exemple |
|------|---------|
| Factuelle | "Quel effet a l'huile sur l'anisotropie dans M03 ?" |
| Lookup ingrédient | "Quelles expériences ont utilisé du psyllium Fibrinel PSL ?" |
| Comparaison | "Comparer les valeurs de SME entre les runs KOBE session 1" |
| Valeur mesurée | "Quels essais ont atteint une anisotropie supérieure à 1,2 ?" |
| Référence | "Quelles expériences référencent ACE-5 ?" |

## Filtrer par chantier

Cliquez sur ⚙️ (paramètres) pour limiter la recherche à un chantier spécifique — ex. *Extrusion HME*, *Applications*, etc.

## Sources

Chaque réponse cite ses sources (expérience + numéro de run). Cliquez sur un lien pour accéder directement au fichier SharePoint.

## Limites connues

- **STRIP-15, STRIP-18, STRIP-B09** : absents du corpus (fichiers non disponibles sur SharePoint)
- **Synthèses KOBE multi-session** (S1+S2 combinées) : résultats partiels
- **`panel_ressemblant_score` KOBE** : donnée non extraite — questions de type "meilleur run couleur" sans réponse fiable
